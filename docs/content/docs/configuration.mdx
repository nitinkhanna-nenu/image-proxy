All configuration is done through environment variables.

## Server

| Variable                   | Default                 | Description                                                                                                                          |
| -------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `IMAGE_PROXY_BIND_ADDRESS` | `0.0.0.0:8000` | TCP address and port to listen on                                                                   |
| `IMAGE_PROXY_ROOT_PATH`    | `/app/data`    | Root directory for serving image files. Unused for image bytes when an S3 bucket is mounted.        |
| `IMAGE_PROXY_STRIP_PATH`   | _(unset)_      | Path prefix to strip from incoming requests. Useful when behind a reverse proxy that adds a prefix. |
| `RUST_LOG`                 | `INFO`         | Log level (`TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR`)                                               |

## OpenTelemetry

OpenTelemetry is a Cargo feature. A build without `--features otel` leaves the exporter out, and the variables below are ignored. `/metrics` is unchanged either way. The Docker image compiles the feature in by default. Pass `--build-arg CARGO_FEATURES=` to build an image without it.

With the feature compiled in, export uses the standard `OTEL_*` variables and stays off until an endpoint is set. Collector headers and the export timeout are read by the SDK and are not written to logs.

| Variable | Default | Description |
| --- | --- | --- |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | _(unset)_ | Collector base URL. Metrics are posted to `<url>/v1/metrics`. |
| `OTEL_EXPORTER_OTLP_METRICS_ENDPOINT` | _(unset)_ | Full metrics URL, used exactly as given. Overrides the base URL. |
| `OTEL_EXPORTER_OTLP_PROTOCOL` | _(unset)_ | `http/protobuf`, or leave unset. Any other value disables export. |
| `OTEL_EXPORTER_OTLP_METRICS_PROTOCOL` | _(unset)_ | Same check. This wins over `OTEL_EXPORTER_OTLP_PROTOCOL`. |
| `OTEL_METRICS_EXPORTER` | _(unset)_ | `otlp` or unset exports when an endpoint is set. `none` turns export off. |
| `OTEL_SDK_DISABLED` | _(unset)_ | `true` turns export off. |
| `OTEL_SERVICE_NAME` | `image-proxy` | `service.name` on the exported resource. |
| `OTEL_RESOURCE_ATTRIBUTES` | _(unset)_ | Extra resource attributes (`key=value`, comma-separated). |
| `OTEL_EXPORTER_OTLP_HEADERS` | _(unset)_ | Headers for the collector. `OTEL_EXPORTER_OTLP_METRICS_HEADERS` wins when set. |
| `OTEL_EXPORTER_OTLP_TIMEOUT` | `10000` | Export timeout in milliseconds. `OTEL_EXPORTER_OTLP_METRICS_TIMEOUT` wins when set. |
| `DEPLOYMENT_ENVIRONMENT` | _(unset)_ | Sets `deployment.environment.name` when present. |

## S3

Set `IMAGE_PROXY_S3_BUCKET` to mount one bucket as the image store. Requests are served from that bucket, and `PUT` writes into it when an upload token is configured. `IMAGE_PROXY_ROOT_PATH` is not read for image bytes while a bucket is mounted. One process mounts one bucket; use `IMAGE_PROXY_S3_PREFIX` as the directory inside it.

Temporary credentials (STS) need the access key, the secret, and a security token. The security token is the AWS session token (`X-Amz-Security-Token`). Long-lived keys omit it. When no static keys are set, the process uses the default AWS credential chain (environment variables such as `AWS_ACCESS_KEY_ID` / `AWS_SESSION_TOKEN`, an IAM role, or a web identity token).

| Variable                            | Default        | Description                                                                                          |
| ----------------------------------- | -------------- | ---------------------------------------------------------------------------------------------------- |
| `IMAGE_PROXY_S3_BUCKET`             | _(unset)_      | Bucket to mount. Unset keeps the local `IMAGE_PROXY_ROOT_PATH` directory.                           |
| `IMAGE_PROXY_S3_REGION`             | `us-east-1`    | Bucket region. Falls back to `AWS_REGION`, then `AWS_DEFAULT_REGION`.                               |
| `IMAGE_PROXY_S3_PREFIX`             | _(unset)_      | Key prefix inside the bucket. `albums` mounts `albums/<request path>`.                              |
| `IMAGE_PROXY_S3_ENDPOINT`           | _(unset)_      | Custom endpoint for MinIO, LocalStack, or R2 (`https://...` or `http://...`).                       |
| `IMAGE_PROXY_S3_ACCESS_KEY_ID`      | _(unset)_      | Access key id. Must be set together with the secret.                                                |
| `IMAGE_PROXY_S3_SECRET_ACCESS_KEY`  | _(unset)_      | Secret access key.                                                                                   |
| `IMAGE_PROXY_S3_SECURITY_TOKEN`     | _(unset)_      | Security token for temporary credentials. `IMAGE_PROXY_S3_SESSION_TOKEN` is an alias.               |
| `IMAGE_PROXY_S3_PATH_STYLE`         | endpoint-based | `true` uses path-style URLs (`endpoint/bucket/key`). Defaults to `true` when an endpoint is set.    |
| `IMAGE_PROXY_UPLOAD_TOKEN`          | _(unset)_      | Bearer token required by `PUT /{filename}`. Unset disables uploads. A single token, no whitespace.  |

The mounted credentials need `s3:GetObject` and `s3:HeadObject` to serve images, and `s3:PutObject` to store them. Secrets are not written to logs.

```bash
IMAGE_PROXY_S3_BUCKET=photos \
IMAGE_PROXY_S3_REGION=eu-west-1 \
IMAGE_PROXY_S3_PREFIX=originals \
IMAGE_PROXY_S3_ACCESS_KEY_ID=AKIA... \
IMAGE_PROXY_S3_SECRET_ACCESS_KEY=... \
IMAGE_PROXY_S3_SECURITY_TOKEN=... \
IMAGE_PROXY_UPLOAD_TOKEN=choose-a-long-random-token \
cargo run --release
```

## Backend

Set `IMAGE_PROXY_BACKEND_URL` to forward API calls that are not images. `GET` and `PUT` of a supported image path still use the mounted store. `/metrics` stays on this process. Every other method and path is sent to the backend with the original method, path, query, headers, and body. Redirects are returned to the caller.

A prefix on the backend URL is prepended. `https://api.internal/svc` plus `POST /api/items` becomes `POST https://api.internal/svc/api/items`. `IMAGE_PROXY_STRIP_PATH` is removed first, the same way it is for images.

| Variable                     | Default | Description                                                                                          |
| ---------------------------- | ------- | ---------------------------------------------------------------------------------------------------- |
| `IMAGE_PROXY_BACKEND_URL`    | _(unset)_ | Backend origin (`https://api.internal` or `https://api.internal/svc`). Unset disables passthrough. |
| `IMAGE_PROXY_BACKEND_TIMEOUT`| `30`    | Seconds to wait for the backend response.                                                            |

The URL must be `http` or `https`, with a host and no user info, query, or fragment. Paths that contain `..` are refused. The caller's `Authorization` header is forwarded; put TLS in front of an `http://` backend.

## Fallback

| Variable                              | Default                 | Description                                                                                                                                  |
| ------------------------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `IMAGE_PROXY_FALLBACK_IMAGE_URL`      | _(unset)_               | Base URL for fetching images not found in the mounted store (e.g., `https://cdn.example.com/images/`)                                        |
| `IMAGE_PROXY_FALLBACK_IMAGE_MAX_SIZE` | `5242880` (5 MB)        | Maximum size in bytes for fallback image responses. Prevents excessive memory usage.                                                         |
| `IMAGE_PROXY_USER_AGENT`              | `image-proxy/<version>` | `User-Agent` header sent when fetching fallback images from an upstream. Loaded into `EncodingConfig`; empty/whitespace falls back to default. |

## Safety Limits

Guards against decompression bombs and out-of-memory conditions. Set any of these to `0` to disable that specific check (not recommended).

| Variable                       | Default             | Description                                                                                                                                                |
| ------------------------------ | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IMAGE_PROXY_MAX_DIMENSION`    | `8192`              | Maximum allowed image width or height in pixels. Images declaring larger dimensions are rejected before a pixel buffer is allocated.                        |
| `IMAGE_PROXY_MAX_SOURCE_SIZE`  | `104857600` (100 MB) | Maximum on-disk source file size in bytes. Files larger than this are rejected with `413 Payload Too Large` before being read into memory. Note: this limit only applies to requests that require decoding or transformation; pass-through requests (no query parameters, source format matches the requested format) stream the file directly without loading it into memory, so the size limit does not apply to them. |

## Format Selection

| Variable                             | Default   | Description                                                                                                                                                                                                    |
| ------------------------------------ | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IMAGE_PROXY_PREFERRED_FORMATS`      | _(unset)_ | Comma-separated list of preferred output formats for [automatic format selection](/docs/formats#automatic-format-selection) (e.g., `avif,webp`). Leaving this field empty disables automatic format selection. |
| `IMAGE_PROXY_ALLOWED_OUTPUT_FORMATS` | _(unset)_ | Comma-separated list of allowed output formats. Requests for unlisted formats get `415`. When unset, all formats are allowed. Leaving this field empty allows all formats.                                     |

## Caching

See [Caching](/docs/caching) for detailed information.

| Variable                          | Default              | Description                                                        |
| --------------------------------- | -------------------- | ------------------------------------------------------------------ |
| `IMAGE_PROXY_ENABLE_CACHE`        | `false`              | Enable response caching                                            |
| `IMAGE_PROXY_CACHE_MEMORY_SIZE`   | `104857600` (100 MB) | In-memory cache capacity in bytes                                  |
| `IMAGE_PROXY_CACHE_MAX_ITEM_SIZE` | `1048576` (1 MB)     | Maximum size of a single cached item. Larger items are not cached. |
| `IMAGE_PROXY_ENABLE_DISK_CACHE`   | `false`              | Enable disk-backed cache (requires `ENABLE_CACHE=true`)            |
| `IMAGE_PROXY_CACHE_DISK_SIZE`     | `536870912` (512 MB) | Pre-allocated disk cache capacity in bytes                         |
| `IMAGE_PROXY_CACHE_DISK_PATH`     | `./cache`            | Directory for disk cache files                                     |

## HTTP Headers

| Variable                           | Default                                  | Description                                                                    |
| ---------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------ |
| `IMAGE_PROXY_CACHE_CONTROL_HEADER` | `public, max-age=31536000, no-transform` | Value for the `Cache-Control` response header. Set to empty string to disable. |
| `IMAGE_PROXY_CACHE_STATUS_HEADER`  | `X-Image-Proxy-Cache`                    | Name of the response header indicating cache status (`HIT`/`MISS`).            |
